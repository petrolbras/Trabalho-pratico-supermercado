Nosso sistemas de pilhas foi implementado com o objetivo de gerenciar as devoluções de produtos do supermercado, onde clientes podem devolver um produto que já compraram. No nosso código, ele permite adicionar produtos na pilha (push), consultar topo e devolver para o estoque (pop)

Todas essas implementações e funcionalidades contribuem para organizar o processamento das devoluções, seguindo o princípio LIFO (last in, first out), no qual o último produto inserido é o primeiro a ser retirado

Um exemplo é adicionar um item à pilha que o cliente quis devolver, esse item fica na pilha até posteriormente ser devolvido ao estoque.

Para compilar e rodar utilize: 

1 - Para compilar os arquivos base -> make
2 - Para rodar o arquivo criado -> make run
3 - Para limpar - make clean
