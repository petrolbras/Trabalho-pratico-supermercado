Nossa lista foi aplicada na parte de estoque no supermercado, servindo como um gerenciador de quantos produtos tem disponíveis no mercado, na nossa implementação ela pode colocar produtos, remover produtos, buscar produtos no estoque, atualizar quantidade de um produto já existente no estoque.

Todas essas implementações e funcionalidades contribuem para a manipulação dos produtos, quais produtos os clientes podem comprar, quando um produto não pode ser comprado (ou pego pelo cliente) e dentre outros.

Para compilar e rodar utilize: 

1 - Para compilar os arquivos base -> make
2 - Para rodar o arquivo criado -> make run
3 - Para limpar - make clean
